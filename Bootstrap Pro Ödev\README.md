# Bootstrap Pro — Agency Site

Bu proje, kurs videosunda seçtiğin üç bölümü birleştirir: hero alanı, hizmet kartları ve sosyal medya/iletişim footer'ı.

## Özellikler
- Bootstrap 5.3.8 grid sistemi ve responsive navbar
- Mor gradient arka plan, dalga ayırıcıları ve hero illüstrasyonu
- Üç hizmet kartı, About Us ve testimonial bölümleri
- Sosyal medya bağlantıları ve mobil uyumlu iletişim footer'ı
- Abonelik formu yerel demo mesajı gösterir; veri göndermez

## Çalıştırma
index.html dosyasını Live Server ile aç. Bootstrap CDN için internet bağlantısı gerekir.
