# HTML CSS Pro — Film Şahı
Sinematik film keşif arayüzü; sağlanan Spider-Man: Far From Home ekran görüntüsünden esinlenmiştir.

## Özellikler
- Siyah üst navigasyon ve sol kısa yol menüsü
- Büyük film hero alanı, Oynat ve Daha Fazla Bilgi demo pencereleri
- Film kataloğu; ada göre arama ve tür filtresi
- Listeme ekle/çıkar ve localStorage ile tarayıcıda saklama
- Tema anahtarı ve mobil navigasyon
- Responsive film/dizi kartları

## Çalıştırma
index.html dosyasını Live Server ile aç. Posterler ve hero görseli internet üzerinden yüklenir. Oynatıcı, hesap ve film listesi eğitim demosudur; gerçek yayın/hesap servisi içermez.
