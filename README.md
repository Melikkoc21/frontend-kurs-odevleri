## Önizlemeler

Her proje klasöründe `demo.gif` önizlemesi bulunur. GIF'ler ekran önizlemeleridir, etkileşimlerin ekran kaydı değildir. React Redux Pro ve React Pro GIF'leri gönderdiğin referans ekranlarından hazırlandı; diğerleri yerel sayfa görüntülerinden üretildi.

## Çalıştırma

React projelerinde proje klasöründe `npm install` ve `npm run dev` komutlarını çalıştır. Diğer projeleri VS Code Live Server ile açabilirsin. Bazı görseller ve harici servisler için internet bağlantısı gerekir.
